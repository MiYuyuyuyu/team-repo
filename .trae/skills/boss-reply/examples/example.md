# 调用示例（examples 给人看）

## 输入

```
场景：催进度
老板原话：这个季度的增长方案什么时候能给我？明天下午之前。
```

## 输出（结构示例，实际文案由模型生成）

```
【回复草稿】
收到。增长方案明天 14:00 前发您评审：今晚完成渠道测算，明天上午补齐风险与备选方案。
若评审通过，周五前可启动投放。时间紧，我先按这个节奏推进，有偏差随时同步。

【备选语气】
- 更直接：明天 14:00 前发您，今晚先出测算。
- 更委婉：我尽量明天上午完成，下午一上班先发您过目，您看可以吗？
```

> 示例只约束结构（草稿+备选语气、承诺处【待确认】），不要求逐字复现——这正是 evals 做结构性校验、不做字符串全等的原因。
